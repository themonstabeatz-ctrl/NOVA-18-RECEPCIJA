==========================================
KORAK 2: KREIRAJ API SERVICE
==========================================

Kreiraj fajl: /src/services/bookingApi.js

Sadržaj:

const BOOKING_API = 'https://spa-dashboard-2.preview.emergentagent.com/api';

export async function fetchServices() {
  const response = await fetch(`${BOOKING_API}/services`);
  return response.json();
}

export function filterByCategory(services, category) {
  return services.filter(s => s.category === category);
}

export function calculatePrice(service) {
  const originalPrice = service.price;
  const discount = service.discount_percentage || 0;
  const discountedPrice = originalPrice * (1 - discount / 100);
  return {
    original: originalPrice,
    discounted: discountedPrice,
    discount: discount,
    hasDiscount: discount > 0,
    savings: originalPrice - discountedPrice
  };
}

export function getDiscountBadgeUrl(discount) {
  if (discount === 5) return '/discount-5.png';
  if (discount === 10) return '/discount-10.png';
  if (discount === 15) return '/discount-15.png';
  return null;
}

==========================================
KORAK 3: AŽURIRAJ SEKCIJU "MASAŽE"
==========================================

U komponenti koja prikazuje masaže (trenutno prikazuje "Tradicionalna tajlandska masaža", "Aroma terapija", itd):

1. Umesto hardkodiranih cena, učitaj ih dinamički:

import { fetchServices, filterByCategory, calculatePrice, getDiscountBadgeUrl } from '../services/bookingApi';

useEffect(() => {
  fetchServices()
    .then(data => {
      const obicneMasaze = filterByCategory(data, "Obicne masaze");
      setServices(obicneMasaze);
    });
}, []);

2. Za svaku masažu prikaži:
   - Ako ima popust (discount_percentage > 0):
     * Prikažu značku sa slikom (getDiscountBadgeUrl)
     * Staru cenu prekriženu
     * Novu cenu sa popustom (bold, crvena boja)
   - Ako nema popust:
     * Samo normalnu cenu

==========================================
KORAK 4: AŽURIRAJ "MASAŽA ZA PAROVE"
==========================================

U sekciji gdje prikazuješ "Masaža za parove" sa dva dropdowna:

1. Učitaj masaže za parove:

useEffect(() => {
  fetchServices()
    .then(data => {
      const coupleServices = filterByCategory(data, "Kartica Masaza za parove");
      setServices(coupleServices);
    });
}, []);

2. U dropdown opcijama prikaži:
   - Naziv masaže
   - Cenu sa popustom (ako ima popust)
   - Pored dropdowna prikaži značku popusta ako izabrana masaža ima popust

3. Pri kalkulaciji ukupne cene:
   - Saberi cene SA primenjenim popustima
   - Ako ima uštede, prikaži staru ukupnu cenu prekriženu i novu cenu
