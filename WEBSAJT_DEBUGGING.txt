🔧 DEBUGGING - Zašto Booking Ne Radi na Websajtu?

========================================
PROBLEM
========================================

Korisnik dobija grešku: "Greška! Molimo pokušajte ponovo."

API ENDPOINT RADI - testirao sam direktno i uspešno kreira appointmente!

Znači problem je na WEBSAJT strani.

========================================
DEBUGGING KORACI
========================================

KORAK 1: Proveri Console Logs
------------------------------

Otvori browser Developer Tools (F12) i pogledaj Console tab.

Kada korisnik klikne "Pošaljite" dugme, da li vidiš:
- Neki error message?
- Network request koji je poslat?
- 404 ili 500 error?

KORAK 2: Proveri Network Tab
-----------------------------

U Developer Tools → Network tab:

Kada klikneš "Pošaljite":
1. Da li se šalje POST request?
2. Koji je URL? (treba: https://spabooking.preview.emergentagent.com/api/book-couple-appointment)
3. Šta je u Request Payload?
4. Koji je Response status? (200, 400, 404, 500?)
5. Šta piše u Response?

KORAK 3: Proveri Request Payload
---------------------------------

Request treba da izgleda OVAKO:

{
  "client_first_name": "Milos",
  "client_last_name": "Stanić",
  "client_phone": "9843768",
  "client_email": "themonstabenzq@gmail.com",
  "start_time": "2025-11-09T14:00:00",
  "duration_type": 60,
  "person1_services": ["service-id-ovde"],
  "person2_services": ["service-id-ovde"],
  "discount_couples_massage": 15.0
}

PROVERI:
- Da li imaš client_first_name i client_last_name (RAZDVOJENO)?
- Da li je start_time u ISO formatu (YYYY-MM-DDTHH:mm:ss)?
- Da li je duration_type broj (60, 90, ili 120)?
- Da li su person1_services i person2_services ARRAY (sa []) i imaju PRAVE service ID-jeve?

========================================
ČESTE GREŠKE
========================================

GREŠKA 1: Pogrešan URL
❌ https://spabooking.emergent.host/api/book-couple-appointment
✅ https://spabooking.preview.emergentagent.com/api/book-couple-appointment

GREŠKA 2: client_name umesto client_first_name i client_last_name
❌ "client_name": "Milos Stanić"
✅ "client_first_name": "Milos"
✅ "client_last_name": "Stanić"

GREŠKA 3: Pogrešan format datuma
❌ "start_time": "09/11/2025 14:00"
✅ "start_time": "2025-11-09T14:00:00"

GREŠKA 4: duration_type je total duration umesto per-person
❌ "duration_type": 240
✅ "duration_type": 120

GREŠKA 5: person1_services nije array
❌ "person1_services": "service-id"
✅ "person1_services": ["service-id"]

GREŠKA 6: Nema pravog service ID-ja
❌ "person1_services": ["undefined"]
✅ "person1_services": ["f99bb0aa-7c87-4bef-bca7-afa0a6fd5535"]

========================================
BRZA PROVERA
========================================

Dodaj console.log ODMAH PRE slanja requesta:

console.log('🔍 DEBUGGING - Request data:', {
  url: 'https://spabooking.preview.emergentagent.com/api/book-couple-appointment',
  method: 'POST',
  body: bookingData
});

const response = await fetch('https://spabooking.preview.emergentagent.com/api/book-couple-appointment', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(bookingData)
});

console.log('🔍 DEBUGGING - Response status:', response.status);
const result = await response.json();
console.log('🔍 DEBUGGING - Response data:', result);

TEST SA FIKSNIM PODACIMA
========================================

Zakomentiraj trenutni kod i testiraj sa FIKSNIM podacima:

async function testBooking() {
  const testData = {
    client_first_name: "Test",
    client_last_name: "Korisnik",
    client_phone: "123456789",
    client_email: "test@test.com",
    start_time: "2025-11-20T14:00:00",
    duration_type: 60,
    person1_services: ["f99bb0aa-7c87-4bef-bca7-afa0a6fd5535"],
    person2_services: ["f99bb0aa-7c87-4bef-bca7-afa0a6fd5535"],
    discount_couples_massage: 15.0
  };
  
  console.log('Testing with fixed data:', testData);
  
  const response = await fetch(
    'https://spabooking.preview.emergentagent.com/api/book-couple-appointment',
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(testData)
    }
  );
  
  console.log('Response status:', response.status);
  const result = await response.json();
  console.log('Response:', result);
  
  if (response.ok) {
    alert('✅ TEST USPEŠAN! Booking radi!');
  } else {
    alert('❌ TEST NEUSPEŠAN: ' + JSON.stringify(result));
  }
}

// Pozovi ovu funkciju direktno iz console-a ili na button click
testBooking();
